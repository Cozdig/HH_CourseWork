# HeadHunter App

## Описание:
Приложение для поиска и создания вакансий.

## Использование:
Запускаете файл main.py, где затрагиваются все реализованные методы. 
Во время работы файла, вы можете создавать свои вакансии, получать их и удалять.

## Реализованные классы:
### Класс HH 
Класс HH в class_api.py нужен, чтобы работала api от HeadHunter. Он выдает словари по 
заданному ключу, в данном приложении это ключ items.
### Реализованные методы в классе:
load_vacancies(keyword) - загружает вакансии с API HeadHunter по ключевому слову

vacancies (property) - возвращает список загруженных вакансий
### Класс UserInputHandler
В классе UserInputHandler реализованы методы для взаимодействия с пользователем.
### Реализованные методы в классе:
ask_for_conf_name() - запрашивает у пользователя подтверждение на поиск вакансий (да/нет)

ask_name_word() - запрашивает у пользователя поисковый запрос (название вакансии)

ask_for_conf_desc() - запрашивает подтверждение на поиск по описанию вакансий

ask_key_word() - запрашивает ключевое слово для поиска в описании

ask_for_confirmation() - запрашивает подтверждение на формирование топа вакансий

ask_for_top_size() - запрашивает количество вакансий для топа (от 1 до 20)

### Класс SearchDescription
В классе SearchDescription реализованы методы для поиска вакансий по заданному слову в описании.
### Реализованные методы в классе:
search_desc(key_word) - выполняет поиск вакансий по ключевому слову в описании
### Класс TopVacanciesCalculator
В классе TopVacanciesCalculator реализованы методы для создания топа вакансий по зарплате.
### Реализованные методы в классе:
calculate_top(top_size) - формирует топ вакансий по зарплате указанного размера
### Класс SearchName
В классе SearchName реализованы методы для поиска вакансий по заданному слову в названии работы.
### Реализованные методы в классе:
search_name(search) - выполняет поиск вакансий по названию
### Класс UserInputHandlerVacancy
В классе UserInputHandlerVacancy реализованы методы для взаимодействия с пользователем.
### Реализованные методы в классе:
ask_for_show() - запрашивает подтверждение на просмотр вакансий пользователя

ask_for_add() - запрашивает подтверждение на добавление вакансии

ask_for_add_vacancy() - запрашивает данные для новой вакансии

ask_for_del() - запрашивает подтверждение на удаление вакансии

ask_for_correct_id() - запрашивает ID вакансии для удаления
